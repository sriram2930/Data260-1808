**Writer draft:**

> A hash table uses a hash function to convert keys into indices for storing elements. If a table is full, the elements are rehashed, meaning a new hash function is applied to compute the new index. When a collision occurs—multiple elements hash to the same index—the elements are resolved using collision resolution techniques. These include chaining, where elements are stored in linked lists at the same index, and open addressing, where a free slot is found to insert the element, ensuring the hash table remains balanced. Chaining is efficient for chaining because it allows for easy rehashing without shifting elements. Linear probing is simpler but may require more rehashing since it sequentially checks elements. Open addressing, while potentially slower, ensures constant-time average performance.
